# Editor Stage 1: Viewer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A read-only egui app that opens a WorldEd `.pzw` project, shows its cells, and draws a cell's `.tmx` tile layers with real tile art.

**Architecture:** Cargo workspace in `rust/`. `worlded-core` (no UI) parses `.pzw`, `.tmx`, `Tilesets.txt` and `.pack` files; `worlded-app` (egui/eframe) draws them. Formats are worked out from real files first (clean-room) and written to `FORMATS.md`.

**Tech Stack:** Rust 2021, eframe/egui, `image` (PNG decode), `roxmltree` (XML), `flate2` (zlib/gzip for TMX data), existing `knoxlots` crate untouched.

**Spec:** `docs/superpowers/specs/2026-11-15-viewer-design.md`

## Global Constraints

- Clean-room: formats come from real files and observed behaviour, never WorldEd source. Contributors who read WorldEd source say so in the PR.
- MIT licensed. Never ship or commit Project Zomboid art or `.pack` files.
- No Qt, WorldEd or KnoxMap at runtime. One standalone Windows exe for the app.
- Damaged input is an error value, never a panic (same rule as `knoxlots`).
- Viewer is read-only: no code path writes `.pzw`, `.tmx` or `.pack`.
- Tests that need a PZ install skip when it is absent.

## Review Focus

- A `.pzw` cell whose `.tmx` path is missing on disk: world view still opens, that cell is marked missing.
- A tile name not found in any tileset: drawn as a placeholder, logged once, no crash.
- A `.tmx` with an empty layer or zero-size map: opens, draws nothing.
- PZ install path unset or wrong: viewer opens with placeholder tiles and a banner.
- A very large world (say 100x100 cells): world view stays responsive; cells are parsed only when opened.

## File Structure

- `rust/Cargo.toml` (workspace): members `knoxlots`, `worlded-core`, `worlded-app`.
- `rust/worlded-core/src/{lib,pzw,tmx,tilesets,pack}.rs`: one file per format.
- `rust/worlded-core/tests/`: one test file per module, fixtures from `rust/knoxlots/fixtures/real/real1`.
- `rust/worlded-app/src/{main,settings,atlas,world_view,cell_view,layers_panel}.rs`.
- `FORMATS.md` (repo root): `.pzw`, `.tmx`, `.pack` layouts as found.
